# Sound Assets

This directory contains sound effect files for the Number Brain game.

## Required Sound Files

Add the following sound files to this directory:

- `button-press.mp3` - Sound when buttons are pressed
- `button-release.mp3` - Sound when buttons are released  
- `operation-success.mp3` - Sound when a valid operation is performed
- `operation-error.mp3` - Sound when an invalid operation is attempted
- `puzzle-complete.mp3` - Sound when a puzzle is successfully solved
- `level-complete.mp3` - Sound when a level is completed
- `menu-navigation.mp3` - Sound for menu navigation

## Audio Format Recommendations

- Format: MP3 or WAV
- Sample Rate: 44100 Hz
- Bit Rate: 128 kbps (for MP3)
- Channels: Mono or Stereo
- Duration: Keep sound effects short (0.1 - 2 seconds)

## File Naming

Use lowercase with hyphens (kebab-case) for consistency.
