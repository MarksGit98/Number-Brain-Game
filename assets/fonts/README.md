# Font Installation

To use the Digital-7 Mono font:

## Option 1: Manual Download (Recommended)

1. Download the font from one of these sources:
   - https://www.1001fonts.com/digital-7-mono-font.html
   - https://www.wfonts.com/font/digital-7-mono
   - https://www.dafont.com/digital-7.font (look for the "mono" variant)

2. Extract the font file (should be named something like `digital-7 (mono).ttf` or `digital-7-mono.ttf`)

3. Rename it to `digital-7-mono.ttf` if needed

4. Place it in this `assets/fonts/` directory (same directory as this README)

5. Restart your Expo development server with: `npx expo start --clear`

## Option 2: Using the Script

Run the PowerShell script: `download-font.ps1` for download instructions.

The font will be automatically loaded by the app using expo-font once the file is in place.
